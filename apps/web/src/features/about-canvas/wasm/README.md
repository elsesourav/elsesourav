# Future WebAssembly Engine Foundation

This directory is reserved for future C++ implementations that will be compiled to WebAssembly (WASM) via Emscripten.

## Why WebAssembly?
While the current particle engine utilizes TypedArrays and a tight `requestAnimationFrame` loop, scaling beyond thousands of particles can stress the V8 engine due to garbage collection spikes or heavy JS-side Math operations. Moving the computationally heavy parts (like iteration and physics force calculations) into C++ will allow us to achieve predictable 60fps on weaker devices by doing bulk memory operations and returning pointers directly to the canvas renderer.

## Intended Structure (For Later)
- `cpp/particle_engine.cpp`: Will implement the exact interface defined in `interfaces.ts`.
- `build/`: Will contain the `.wasm` binary and `.js` glue code generated by Emscripten.

For now, the TypeScript engine strictly adheres to data-oriented design paradigms to make the eventual transition to WASM trivial.
