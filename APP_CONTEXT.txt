1. PROJECT OVERVIEW
================================================================================

ElseSourav is a portfolio-driven developer platform and app marketplace built as
a monorepo. It blends public app discovery, personalized user features, a blog/
help center, and a full admin control center powered by a microservice architecture.

Name:       elsesourav
Version:    0.1.0
License:    MIT
Monorepo:   npm workspaces

Tech Stack:
  Frontend:    Next.js 16 (App Router), React 19, TypeScript 6, Tailwind CSS 4
  Backend:     Express 4 microservices, TypeScript
  Database:    PostgreSQL 16 (Prisma 7 ORM)
  Cache:       Redis 7
  Auth:        NextAuth v5 (JWT sessions)
  State Mgmt:  Redux Toolkit, TanStack React Query
  UI:          MUI 9, Radix UI, Framer Motion, Lucide Icons, Tiptap Editor
  3D/WebGL:    Three.js, React Three Fiber, WASM (C++ particle engine)
  Styling:     Tailwind CSS 4, CSS Modules, Glassmorphism components
  Testing:     Vitest, Supertest
  Deploy:      Docker Compose (Postgres + Redis)

Workspaces:
  apps/*        — Frontend applications (Next.js web app)
  packages/*    — Shared libraries (db, config, cache, types, validation, queue)
  services/*    — Backend microservices (auth, catalog, user, content, theme)

5. REQUEST FLOW
================================================================================

  Browser ──→ Next.js App Router (pages/api routes)
                │
                ├─ Server Components: fetch data via service-client.ts
                │    (adds x-internal-token, x-user-id, x-user-role headers)
                │
                ├─ API Routes: proxy requests via route-proxy.ts
                │    (validates session, forwards to backend service)
                │
                └─→ Backend Microservices (Express)
                      │
                      ├─ Internal auth middleware (verifies x-internal-token)
                      ├─ Admin middleware (checks x-user-role === "ADMIN")
                      ├─ Business logic
                      └─→ PostgreSQL (via Prisma ORM)

─────────────────────────────────────────────────────────────────────────────────
9.4 DATABASE CONVENTIONS
─────────────────────────────────────────────────────────────────────────────────

  • IDs:           CUID strings (@default(cuid()))
  • Timestamps:    createdAt (auto), updatedAt (@updatedAt)
  • Soft deletes:  deletedAt DateTime? on User, Category, App, Post
  • Column naming: snake_case via @map()
  • Table naming:  plural snake_case via @@map()
  • Cascades:      Child records cascade on parent delete
  • Restrict:      Payment → User/App (prevent accidental delete)
  • SetNull:       Optional FKs nullified on parent delete
  • Text columns:  Long content uses @db.Text (no length limit)
  • Decimals:      @db.Decimal(10,2) for money, @db.Decimal(3,2) for ratings
